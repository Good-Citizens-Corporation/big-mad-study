## What is still open because of this review

- The reviewer has not read the questionnaire. **The plan is not filed until they have** (or another person has).
- **[DECIDE]** SES measure and coding; whether personality is collected; threshold for the between-person effect; write-in promotion thresholds; relief "I don't know" ceiling (proposed 30% per destination); day-level missingness rule (proposed 50% of completers' check-in days).
- The power simulation now has to be run per contrast (H1 and H1a use different subsets of entries).
- The consent and privacy drafts must name the added screener items (age, gender, profession, SES) before counsel and the IRB see them.
